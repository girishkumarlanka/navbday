# For Navya — Interactive Birthday Experience

A romantic, cinematic React birthday microsite built with **React + Vite + Framer Motion + Lucide**.

## Run it

1. Install Node.js.
2. In this folder run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the local Vite URL.

## Add Navya's background music

Put your MP3 file here:

```text
public/music/navya-birthday.mp3
```

Then restart/reload the site.

The music:
- Starts when she clicks **Start the journey**.
- Loops continuously through the experience.
- Can be paused/resumed using the music button in the top-right.
- Uses a user interaction to satisfy modern browser autoplay restrictions.

## Personalize it

Open `src/main.jsx` and replace the five `[Write here ...]` placeholders with your own messages.

The experience has:
- Animated opening screen
- 6-chapter progress journey
- Smooth page transitions
- Floating hearts and ambient glow
- Responsive mobile layout
- Background music controls
- Cinematic final birthday reveal
- Animated sparkles + confetti
- A final “Make a wish” interaction
